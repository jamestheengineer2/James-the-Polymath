SR Latches

The SR Latch is a bistable circuit which utilizes two NOR or NAND gates in conjunction to create an evocative response to input changes.

Credits to Stack Exchange for the Image

As shown in the diagram below, the circuit has two inputs labeled “S” and “R”. The S stands for Set while the R stands for Reset. These are attached to a combinational logic circuit of two NOR gates. This latch is used to create “memory” of the previous inputs, and dynamically control future desired inputs asynchronously. A truth table corresponds to the SR Latch inputs.

Before the activation of an SR Latch, it boots in an unpredictable state. This is because the initial output directly depends on the previous states, leading to a chicken-or-the-egg causality dilemma. Thusly, do not use the SR latch if your circuit design depends on previous states to be preconfigured to certain signals.

When S = 0 and R = 0

When "S" is set to zero, and "R" is set to one, there is no change in the circuit. Since both inputs are set to zero, there will be no drive for change within the NOR gate. The only factors governing such change are the inputs Qt and Qt+1. Due to the nature of NOR gates - when inputs of one leg are zero, the corresponding NOR gate returns the opposite of the second input.

The image above adds the Qt and the Qt+1 entries to the logic gate, where Qt+1 is a function of the table. The Qt represents the complement of Q in a circuit, while the Q represents the future input of the circuit. Additionally, the “t” subscript represents the current clock signal. This can intuitively be represented as Qt+1 representing Q in t+1 clock signals from now.

When S = 1 and R = 0

When “S” is set to one, while “R” is set to zero, it creates a signal to “set” Qt+1 to 1. The second input does not matter since a value of 1 in a NOR gate guarantees a 0. The newly created output of Qt “flows downstream” to the bottom NOR gate. The output of the second NOR gate depends on the input of R, which in this case is set to 0. Both of these zeroes beget 1. The 1 signal is sent to Qt+1. When we stop sending a signal to the “S” input, the Qt retains its value due to the constant 1 signal sent from Qt+1.

When R = 1 and S = 0

When "R" is set to one, while "S" is set to zero, it creates a signal to "set" Qt+1 to 0. When the top NOR gate recieves a signal of 1, the NOR gate defaults to 0. This signal makes its way to the Qt+1 input. From the Qt+1 input, it "flows downstream" in conjunction with the "S" input which is also 0. These two inputs create a NOR output of 1. This input "flows upstream" to the Qt input, now with a value of one. This Qt now ouputs a signal "downstream" to one of the inputs of the top NOR gate.When the reset input is turned off, the Qt value outputting 1 still maintains that Q cannot become 1.

When R = 1 and S = 1

When "R" is set to one, and "S" is set to one, the SR latch starts in an unpredictable booting state. This is due to the mechanical interlock shown between the combinational logic circuits. Such interlock guarantees that Qt and Qt+1 are alwaus complements of eachother. When an input is set to 1, its corresponding NOR gate returns 0. Thusly, setting both inputs to 1 would make both NOR gates zero, which is impossible due to the structure of the mechanical interlock. This leads to an uncertain state where when pressed at the same time - the first input to send an electrical signal is the one to initiate the cycle.
