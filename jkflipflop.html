JK Flipflops

The JK Flipflop is an advanced modification of the SR Latch. It takes the idea of the clock signal from the D Latch, while retaining both of its inputs like that of the SR Latch. Although this is a huge development in terms of latches, the truth table becomes more complicated as there are three inputs instead of two. Similar to the D Latch, the computer only "listens" when permitted by the enable signal. And the two inputs J and K use NAND gates to create memory in Q and Q'.

Analyzing the circuit closely, we notice that the left contains the newly established inputs J, K, and CLK, while the right side is the familiar SR Latch circuit. Following a similar pattern to a D Latch, the JK Flipflop uses two NAND gates which generate inputs for which to plug into the SR Latch. But enough about the theory - lets see the circuit in action.

When CLK = 0

I'm sure you guys are already well aware of what a flipflop does when not enabled, but I'm just putting this in here for continuity. When not enabled, the NAND gate is guaranteed to return 1 due to a 0 being in the NAND truth table. Thusly, both an "S" input and "R" input will be 0, causing no change within the circuit. For all circuits with "Enable" or "CLK" (these mean the same here), the circuit will have no change. For the following proofs, assume the circuit is enabled (CLK=1).

When J = 1, K = 0

When J is set to 1 while K is set to 0, Q is set to 1. This is because when we NAND J, CLK, and Q' on the top-left NAND gate (assume Q' is 1), the output returns 0. This 0 goes through the SR Latch - specifically the "R" input - and changes nothing as there is no signal. The bottom-left NAND returns 1, as K is 0. This 1 goes through the "S" input of the SR Latch, thusly setting Q to 1.

When K = 1, J = 0

When K is set to 1 while J is set to 0, Q is reset to 0. This happens because when we NAND CLK,K, and Q (assume Q is 1) on the bottom-left NAND gate, the output returns 0. This 0 runs through the SR Latch - specifically the "S" input - and changes nothing as there is no signal. The top-left NAND gate returns 1, as J is 0. This 1 runs throught the "R" input of the SR Latch, thusly setting Q to 0

P.S: I hope you are noticing a pattern that when an input of an SR Latch is a value, its other input is set to its complement. For example - when S is 1, then R is 0. When a value is inputted within a discussed circuit variable (J, K), the SR embedded circuit will have complemented values for S and R.

When K = 1, J = 1

When both J and K are set to 1, a new phenomena occurs which we have never discussed before. Toggling. We can think of toggling as a modified state of the SR Latch's undefined state. Instead of booting in an unpredictable state, it is oscillating between Q=1 and Q=0 millions of times a second. This simple fact becomes very important as we move to our final switch, the T Flopflop, which essentially is built from this idea.

JK Flipflop Summary

We finally learned about a circuit which tolerates and uses all 4 input states. Additionally, we get our own clock signal integrated into the circuit. All of these factors make the JK Flipflop not just the most complex circuit but also the most useful. Congrats on learning about the JK Flip Flop!
