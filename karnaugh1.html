Karnaugh Map (Part 1)

We have talked quite extensively about minterms/maxterms and their applications in boolean algebra. Finally, we are going to see this in action with the Karnaugh Map (K-Map). This is one of the most versatile maps in boolean algebra, and allows you to evaluate minterms and maxterms from a function of literals.

Lets say that we have a list of 8 literals, and our goal is to find the ruleset of variables that each function in the literal is following. We can write the minterms or maxterms of each literal, and fill out our K-Map with the determined values. After all calculations are done, we can find the original ruleset of which each and every literal follows.

Grey Code

The first thing we must discuss is grey code. Instead of using standard boolean counting, the K-Map uses a special syntax called grey code.

Consider that we are counting in boolean algebra. We go in series of 00, 01, 10, 11 and so on. However grey code has restrictions on the number of digits are changing. For instance, when counting from 01 to 10, we notice that the first and second digit change states. This is not permitted in grey code counting, as only one digit may change. For this, we will always skip to the next logical number in the boolean counting series. Then the number that we skipped will come after the number that changed 1 digit. Thusly, after 01 is 11. See how only one digit changes?

When constructing a K-Map, you must use the Grey Code. Not doing so will result in an inaccurate result. Although you will rarely use Grey Code beyond 4 numbers of the series, on this website our goal is to take you the extra mile. Here are the first 16 numbers in the series of Grey Code.

Functions

We have also been learning minterms and maxterms to lead up to the concept of functions. A function is a series of literals with an evaluation of the final result. There are two sections - the literal section and the final evaluation section. The literal should be unique for all strings of numbers, and is typically written in order of binay. Take a look!

ABC Function

With just these two categories on their own, we do not have enough information to fill out the Karnaugh Map. To complete this all the way, we must evaluate the minterms or maxterms of the ABC solution. Here is our adjusted table with all minterms. There are cases where you should choose one over the other when dealing with minterms and maxterms. This will be further justified in the next article of the Karnaugh Map, but a general rule of thumb applies. When there are more 1s in the function then 0s, then use minterms. However when there are more 0s in the funciton than 1s, use maxterms. Again, this rule will be justified further when dealing with Karnaugh Maps in the future.

Sketching the K-Map

Using all of the information that we just learned, we will sketch the K-Map. A K-Map is a grid, and the number of boxes in the grid must be of 2^n. This function is valid since there are 8 (2^3) literals.

There are multiple layers in the K-Map. The minterm # corresponds to the base-10 number conversion of the grey code labels.For instance, if grey code has the label "11", the conversion would be to 3 in base-10. This 3 corresponds to the minterm number 3. Since the K-Map has rows, we simply continue counting from the line break. Accounting for the syntax of Grey Code, it is important to rearrange the minterm # when there is a deviation of Grey Code from standard binary counting.

Notice that the Karnaugh Map has numbering that is different than expected when dealing with Grey Code. This is because we are doing direct binary conversions from Grey Code. So the "11" section translates to 3 in base-10. This 3 should match the minterm #3. As the layers move down in the K-Map, the numbering of minterms increase. Also, we often call these K-Maps "3 Variables" since the Grey Code is often converted into its minterm/maxterm form. This K-Map requires 3 variables to represent the Grey Code maxterms/minterms.
