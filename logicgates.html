Logic gates are the building blocks of all electronics. We use these to perform all mathematical and logical operations. When using logic gates, there are seven major variants that come to play. These designs and constructions will be covered in more detail in this article. Without further to do, lets commence this article!

Boolean Theory

Boolean Theory is a sector of mathematics where two logical choices can exist. These choices are represented by 0 (False) and 1 (True). This was initially a sector for representing logical choices such as “There is a dog and there is a cat” (D∧C). However boolean algebra started getting discussed more in detail due to the use of computers.

Computers can only understand basic electrical signals. Electric signals run off electricity, which by nature causes movement (electromagnetism), performs logic (logic gates), and lights (electrodynamics). Having enough of these electrical signals, we can construct any series of commands that we want. This current boolean signal follows the structure of “if a signal is sent, do that, otherwise do this”. This structure is useful, however we may want more dynamic logic such as “if two signals are sent do that, otherwise do this”. Logic gates give us a chance to use this more dynamic approach.

Logic Gates

Learning how logic gates work, I will brief you on the simplest logic gate that there is - the NOT gate.

As there are two possible states in boolean algebra, the NOT gate simply switches the state to the opposite. For this example, the 1 swaps to 0. This also corresponds with the truth table, which states that for each input, an opposite output is returned.

AND & OR Gates

Finally, we will get into the bread and butter of logic gates - the AND and OR operation.

  • The AND logic gate outputs a 1 only when A and B are 1. Therefore both A AND B have to be 1. If A or B are something different from 1, then the output will return a 0.
  • The OR logic gate outputs a 1 when either A or B are 1. Therefore either A OR B have to be 1. If neither A nor B are 1, then the output will return a 0.

XOR Gates

The XOR gate is the next logical step of the OR gate. What if we want a value to return 1 when two things are mutually exclusive? Then the XOR gate is our best friend. The X in XOR stands for exclusive, and indicates that there will only be exclusively OR operations. This means that A=B=1, and A=B=0 are not permitted. This comes in handy when dealing with events that should not happen both at once.

Complementary Gates

Before further gates, I must introduce you to the concept of complementary gates. These are dynamic duos, and work in conjunction. Both of them have completely opposite logic which govern their operations.

For example, take the NAND gate which is the complementary gate of the AND gate. While the AND gate returns 0 unless both inputs are 1, the NAND gate returns 1 unless both inputs are 1. The only difference between the two is the returning of the output. For this reason, when we examine the truth table, then both the outputs should be opposite of each other.

Representation of the NAND Gate

Notice that the NAND gate is completely opposite of the AND gate’s truth table. Since the AND and NAND gate follow completely opposite sets of rules, they will never have the same output from two inputs. The “circle” on the left of the gate indicates that it is the complementary gate. The NAND can be represented as the AND gate with a circle on the left.

NAND Gates

The purpose of the NAND is to return true unless both A and B are 1. This is the direct opposite of the AND gate which will only return true when both outputs of 1. This gives us our first complementary gate pair. The NAND can be thought of as a logic gate we use when two events should never happen at the same time.

NOR Gates

The NOR Gate is the complementary gate to the OR gate. Unlike the OR gate which can be thought of as a logical 1 detector; the NOR gate detects 0s. XNOR Gates

Finally, we have reached our last complementary gate. This is complementary to the XOR gate. While the XOR gate evaluates whether both inputs are a different value and returns 1 if true; The XNOR gate evaluates if both inputs are the same. This logic gate would be used if we either want two inputs to happen or not happen.

Review of All Gates

  • NOT Gate returns the opposite of the input entered
  • AND Gate returns 1 only when A and B are 1
  • OR Gate returns 1 when either A or B (or both) are 1
  • XOR Gate returns 1 when A and B are different values
  • NAND Gate returns 1 when both A and B are not 1
  • NOR Gate returns 1 when neither A nor B are 1
  • XNOR Gate returns 1 when A and B are the same value
